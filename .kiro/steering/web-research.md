# Investigación web y evidencia externa

Activa este steering cuando el análisis requiera contexto actual, definiciones externas, benchmarks, documentación o verificación de una afirmación.

## Política de fuentes
- Priorizar fuentes primarias: organismos públicos, documentación oficial, artículos originales, registros regulatorios y publicaciones de la organización responsable.
- Usar fuentes secundarias solo para descubrir contexto o cuando la primaria no esté disponible; declararlo.
- Para afirmaciones importantes, contrastar al menos dos fuentes independientes cuando sea posible.
- Registrar título, entidad autora, URL, fecha de publicación y fecha de consulta.
- No usar un fragmento del buscador como evidencia suficiente; abrir y revisar la fuente.
- Separar hechos de la fuente, interpretación del analista y recomendación.
- No citar una página que no respalde exactamente la afirmación.
- Verificar la fecha de vigencia y señalar si una fuente puede haber quedado desactualizada.

## Privacidad y seguridad
Nunca enviar a un servicio externo filas identificables, credenciales, tokens, rutas privadas, secretos ni datos de clientes. Sustituir valores por ejemplos sintéticos o agregados y pedir autorización si el análisis externo requiere información sensible.

## Formato mínimo de citas
Para cada afirmación externa: `[Entidad o título](URL) — publicada: AAAA-MM-DD; consultada: AAAA-MM-DD.` Añadir una nota breve sobre qué parte de la fuente se utilizó y qué no demuestra.
