# Tareas: flujo experto de análisis de datos

- [ ] 1. Crear el agent `data-analyst-expert` con herramientas y recursos explícitos.
  - [ ] 1.1 Incluir lectura, escritura, shell y búsqueda web.
  - [ ] 1.2 Referenciar steering, Specs y las skills analíticas.
- [ ] 2. Configurar los principios permanentes y el flujo automático de análisis.
  - [ ] 2.1 Añadir reglas de rigor, privacidad, trazabilidad e incertidumbre.
  - [ ] 2.2 Añadir activación por archivos de datos.
- [ ] 3. Implementar las skills de exploración, calidad y comunicación.
  - [ ] 3.1 Documentar pasos, técnicas, entradas y formato de salida.
  - [ ] 3.2 Mantener las instrucciones enfocadas y sin duplicar el steering.
- [ ] 4. Verificar el flujo con una fuente de prueba sintética.
  - [ ] 4.1 Comprobar perfilado, faltantes, duplicados y granularidad.
  - [ ] 4.2 Comprobar que las cifras incluyen periodo, unidad y denominador.
  - [ ] 4.3 Comprobar que el informe incluye limitaciones y receta reproducible.
- [ ] 5. Revisar seguridad y reproducibilidad antes de adoptar el agent.
  - [ ] 5.1 Confirmar que no se exponen secretos ni datos identificables.
  - [ ] 5.2 Confirmar que las fuentes originales no se sobrescriben.
